# Week 4 – Data Visualization and Reporting for Agribusiness Insights

## Project Overview

This project focuses on analyzing agribusiness data and presenting meaningful business insights through data visualization. The project was completed as part of the Week 4 task on Data Visualization and Reporting for Agribusiness Insights.

## Objective

The objective of this project is to transform agribusiness data into clear and meaningful visualizations that can support business analysis and decision-making.

## Tools Used

- Microsoft Excel
- Microsoft Word

## Visualizations Created

The project includes the following visualizations:

1. Revenue by Region
2. Revenue by Product
3. Monthly Revenue Trend
4. Revenue Share by Product
5. Sales vs Revenue Scatter Plot

## Key Insights

The visualizations help identify differences in revenue across regions and products, monthly revenue trends, product contribution to total revenue, and relationships between business variables.

These insights can help agribusiness organizations understand their sales performance, identify strong-performing products and regions, and make better business decisions.

## Files Included

- `Week_4_Agribusiness_Data_Visualization.xlsx` – Excel workbook containing the data analysis and visualizations.
- `Week_4_Agribusiness_Report.docx` – Detailed report containing visualization explanations, findings, insights, and recommendations.

## Conclusion

This project demonstrates the practical use of Microsoft Excel for data visualization and business reporting. It also highlights how visual data analysis can support strategic decision-making in the agribusiness sector.
